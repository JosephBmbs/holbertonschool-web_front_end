## 📝 Description

This project is a hands-on introduction to **CSS Flexbox**. 
we’ll explore how to use flex properties to control layout and alignment
and complete a set of interactive quizzes to reinforce your learning.

## 🎯 Learning Objectives

By the end of this project, you should be able to:

- Explain what Flexbox is
- Convert float-based layouts to flex-based layouts
- Horizontally and vertically align elements using Flexbox
- Distinguish between the **main** and **cross** axes
- Identify properties that apply to **flex items** vs **flex containers**
- Use shorthand properties for Flexbox
- Create a web page layout using Flexbox
